♠ 低階 PLO 打法筆記

這頁整理自 一清（ngarina） 的 PLO 心得，內容針對 PLO25 以下 的低階牌局。 原文是聊天紀錄，這裡只做分段與排版，牌組寫法與判斷都保留原樣，沒有改動他的結論。 看不懂的縮寫可以直接跳到最下面的名詞小抄。

翻前開牌 目標數據 為什麼這樣好打 Set 的陷阱 被 Flop Raise 之後 SPR 與慢打 3-bet 之後 名詞小抄

翻前開牌（依位置）

EP / UTG
6789 dbs ～ 89TQ(Qs)　（789J、789Q、89TK dbs+） AAxx（AA27 no suited 也許可以不開） KKxx（xx 要 sc、要有 suited，例如最爛大概是 KKs57，7s 可能可以放棄） QQTJ、QQ89（要有 Qs，剩下兩張都要跟 Q 有關聯）、QQ dbs+ JJT9 dbs（只有一個 suited 的話，或許可以不開） AKQJT 任選四張，有 suited 應該就可以開 AKQ Ks+（類似 AKQ4，EP 還是開 As+） AQJ As+　／　ATJ As+ AQQT Qs+　／　AKKT Ks+　／　AJJ8 As A+Q dbs+ 兩大對：99TT+

3388 沒 suited 可能可以丟棄。

5566 dbs 看起來是很好的牌，但在 UTG、又是剛開始玩這個打法的階段， 一清認為不太妥，直接棄掉無妨。

MP / UTG+1

比 EP 鬆一點點：

QQ → 可以變 JJ JJ → 可以變 TT AKQ Ks → 可以變 Qs （以此類推）

但 ATJ Js 的話，最後一張要是 7～9，例如 ATJ7、ATJ8 Js。 這類看起來相對差一點的牌，如果 BTN 跟 CO 很機歪，可以不開。

CO

看 BTN 是什麼人。沒人 open 的情況下：
· BTN 鬆 → open range 跟 MP 一樣
· BTN 緊 → 我們就快要是 BTN 的 steal range 了

BTN

沒人 open 的話，基本上自己覺得是好牌就可以 steal。 一清的例子：像 2336（2s）他都 open；被 3-bet 就看對手是什麼人，可以選擇性蓋牌。

SB

一開始能不玩就不玩。爛 AA 用跟的、或直接 fold 都無妨——OOP 很難打。

3-bet：只 3-bet J+ dbs hands，且對手在兩個以下 對很多人（squeeze）：只能是 Q+ dbs，而且最好要有 As

「最好要有 As」這件事，跟 flop 之後能不能「大膽」繼續有很大的關係。

BB

最後一個做決定，很多牌都可以 call 2BB 內進去。 自己覺得很難拿捏的牌（例如 4456 6s、JJ67 7s、3457 7s）fold 無妨—— 特別是還不太會打 3-bet pot 的時候。

照這樣打，數據會長什麼樣

VPIP（BTN 與 CO 有掌握住 steal）約 20%
PFR（3-bet 很低、當個孬孬 PLO 初期玩家）約 13%

一清的說法是：這樣在 PLO25 以下應該是輕鬆撿。

為什麼這套 range 好打

這樣的 range 跟玩 hold'em 初期很像，而且可能更輕鬆。 我們選擇的手牌在 flop 有 draw 的情況下，都可以很無腦地打完—— 因為我們的 draw 都會是大 draw，比較不會犯錯。

PLO 的 draw 比 set 好打。— 一清

Set 的陷阱：新手輸最多錢的地方

初期新手 set 會輸很多錢，原因是 PLO 沒有 redraw 的 set（side card 沒用）。 自己 flop nuts 的狀況下，遇到肯跟我們繼續的牌組，一清估的總勝率大約是：

Flop 頂 set vs 願意繼續的牌55 / 45
Turn 之後（對手買到、或還在買）36 / 64
對手買到時，set 只剩20%
對手沒買到時，set 有50–60%

因為太多 draw 在 turn 上有 40–60% 的勝率，有一些 draw 在 turn 上甚至是領先 nuts 的。

例子：QsTs6c4c vs 7s8s9cJc —— 後者應該是領先 QQ 一點； 789J 沒得買花，也有 46% 對上所有的 QQ。

所以一開始 set 要小心玩，尤其 OOP 的 set 沒有 redraw， 不要一開始就丟太多錢進去。一清自己的話：「我兩三年前輸很多錢在這了。」

被 Flop Raise 之後，可以打完的牌

AX 中一個胚，可以買 A 花（前提：flop 沒有順） KK + FD wrap 帶 Q 花以上 雙頭帶 K 花 中洞帶 A 花 有順在上面的話，我們 set 帶買花

Over pair 買 set 會贏、又有一點點 draw：100BB 內的 3-bet pot 幾乎都能去。

反過來，AQKJ 這類的牌，你在 EP／MP 被 3-bet，如果你不是 A 的同花聽牌、 對手 3-bet 頻率也不算高，其實直接扔掉無妨。

在低階 PLO 選牌是最重要的。另外，有位置可以玩更多的牌，甚至在 BTN limp in 也 OK。 — 一清

SPR 對的話，基本上不慢打

下面是一清舉的實例，說明慢打在 PLO 為什麼容易出事：

3BB open，flop 是 69Q 兩張紅心，我們拿裸 QQAK、沒有紅心， 翻前有兩個 call。

Flop 底池 10.5BB，我們 OOP 頂多 bet 10.5。
Turn 開紅心，或是 5、7、8、T、J、K 這些牌，基本上動彈不得——尤其是紅心 K。 我們甚至連買葫蘆都沒得玩了。 — 一清

結論是：牌面爛到這種程度，你反而沒必要閃，因為底池已經太多錢了。

假設你頂 set 被 flop raise，你 re-raise all in 打完， 你的 equity 長期走下來是對的。
但如果你 bet 被 raise、閃一隻，turn 開 7 打完，結果對手真的是順子—— 這樣你的 equity 就是錯的，你打得就不理想。 — 一清

3-bet 之後不怕 4-bet、可以 call 下來看 flop 的兩種牌

1. 像 AAxx 2. 像 78TQ ss 這種沒有 A、不會被 dominate 的牌

兩 suited 又不到 A 的牌，比較不怕被 4-bet call 了被當（dominate）。 也就是 3-bet、call 4-bet，flop 可以打完。

名詞小抄（非原文，方便對照）

dbs / ds（double suited）
四張牌剛好是兩組同花色，例如 A♠K♠Q♥J♥。dbs+ 表示這個等級或更好。
Xs（例如 Qs、As）
指那張牌帶著同花花色，例如「QQTJ 要有 Qs」＝要有一張 Q 跟別的牌同花。
sc（suited connector）
同花連牌，例如 KK 後面那兩張要能連、又要同花。
FD（flush draw）
同花聽牌。A 花＝聽最大的同花（nut flush draw）。
wrap
PLO 特有的多面順子聽牌，出牌數遠多於 hold'em 的兩頭順，常常 13～20 張 outs。
雙頭 / 中洞
兩頭順（open-ended）／內張順（gutshot）。
redraw
已經成牌之後，還能再往更大牌型進化的機會。PLO 的 set 沒有 redraw 就是這裡說的弱點。
SPR（stack-to-pot ratio）
有效籌碼 ÷ 底池。SPR 低＝口袋淺，成牌就該直接把錢放進去，不用慢打。
squeeze
前面有人 open、又有人 call 之後才 3-bet，把中間的人夾在中間。
dominate（被當）
牌型被對手的同型態壓制，例如同樣聽花但你的花比較小。
VPIP / PFR
主動投錢入池的手數比例／翻前加注的手數比例，是判斷鬆緊的兩個基本統計。
