    被 3-bet（4-bet / 跟注 / 棄牌）

    自己在翻前開牌後被 3-bet 的應對 range（預設 100bb，可拉滑桿試算 10–300bb）。 9-max 那組是現場取向：那邊的 3-bet range 很緊很偏價值，所以續玩要比 6-max 收得多。 紅 = 4-bet、綠 = 跟注、灰 = 蓋牌。 按「✏️ 編輯」後點格子循環切換 棄牌 → 跟注 → 4-bet。

    面對 4-bet（你 3-bet 後被 4-bet 回來）

    翻前樹的最後一個節點：你照防守圖 3-bet，開牌者 4-bet 回來 —— 紅 = 5-bet（淺籌碼＝全下）、綠 = 跟注、灰 = 蓋牌。 JJ、AQs、AKo 這些牌在這裡最難拿捏，也是一次錯就是整疊的地方。

    ⚠️ 跟冷 4-bet 一樣，這個決定對「對手 4-bet 多寬」極度敏感： 對只拿 QQ+ 4-bet 的對手，連 KK 都只需要跟注；對會拿 A5s、AKo 亂 4-bet 的對手， QQ/JJ/AK 全部變成明確續玩。先判斷對手是哪種人，再看圖。

    續玩寬度由兩層夾住：上限是 MDF × 你的 3-bet range（讓對手的 4-bet bluff 無利可圖）， 下限是底池賠率。你 3-bet range 以外的手牌照理不會走到這個節點，那些格子僅供參考。 唯讀（沒有手打的建議表可編輯）。

    冷 4-bet / 冷跟（前面開牌 + 有人 3-bet）

    第四種翻前局面：別人開牌、第三家 3-bet，而你還沒行動。 紅 = 冷 4-bet、綠 = 冷跟、灰 = 蓋牌。

    ⚠️ 這個決定對「對手 3-bet 多寬」極度敏感，所以寬度做成滑桿而不是寫死。 例：BTN 拿 AQo，對手 3-bet 3.6% 時你只有 33.5% 勝率、要 40% 才跟得起 → 蓋牌； 同一手牌對手若 3-bet 到 9%，勝率變 47.6% → 變成跟。先判斷對手多寬，再看圖。

    模型只算「對上 3-bet 者」的勝率 —— 開牌者多半會棄或被擠掉，且他的 range 較弱。 但若開牌者也跟進變成三人底池，你的實際勝率會更低，所以這裡給的是偏樂觀的上限。 唯讀（沒有手打的建議表可編輯）。

    情境是完整矩陣：你的位置（CO / BTN / SB / BB）× 你前面每一組「開牌者 → 3-bet 者」， 6-max 20 格 + 9-max 74 格，選單先按你的位置分組。更前面的位置沒做 —— 後面壓著四家以上， 冷跟幾乎必被再擠，冷 4-bet 也只剩 QQ+/AK。

    Squeeze / 過牌跟（前面開牌 + 有人平跟）

    現場最常見的多人局面：開牌者加至少一個跟注者在你前面。 紅 = squeeze、綠 = 跟注、灰 = 蓋牌。 跟單挑防守差最多的地方：跟注要更緊（三人底池勝率被分掉）、3-bet 要更大（squeeze，死錢多了一份跟注）。

    跟注者的 range 是封頂的 —— 拿得出 QQ+/AK 的人多半直接 3-bet 不會平跟， 所以 squeeze 的 fold equity 比單挑 3-bet 高。模型只算對開牌者的勝率（他是比較強的那個 range）， 跟注者的影響用「跟注門檻加一層＋隱含賠率加成調高」表述； 平跟寬度另外錨定在跟注者的平跟 range 上，按你的位置縮放。唯讀（沒有手打的建議表可編輯）。

    情境是完整矩陣：你的位置（CO / BTN / SB / BB）× 你前面每一組「開牌者 → 跟注者」， 6-max 20 格 + 9-max 74 格，選單先按你的位置分組。

    面對 squeeze（你開牌、有人跟注後被 squeeze）

    Squeeze 圖的鏡射：你開牌、有人平跟，第三家 squeeze 回來 —— 紅 = 4-bet（淺籌碼＝全下）、綠 = 跟注、灰 = 蓋牌。 對手的預設 squeeze range 直接取 Squeeze 圖那格算出來的結果，兩張圖不會講不同話。

    跟面對 4-bet 差在兩件事：底池多一份死錢（跟注者的 2.5bb，他面對 squeeze 大多會棄） → 跟注價格較好；但跟注者還沒表態，偶爾會跟進變三人底池甚至反擠 → 跟注門檻加一層。 squeeze 常來自盲注，這時你翻後反而有位置，邊緣牌比面對 4-bet 更能用跟注續玩。

    ⚠️ 一樣對「對手 squeeze 多寬」極度敏感：現場多數人的 squeeze 偏純價值（QQ+/AK）， 那種人 squeeze 你就把寬度拉低、乖乖蓋牌；會拿 A5s、KQs 亂擠的人才值得你反擊。 續玩上限 = MDF × 你的開牌 range（份額打折：跟注者也要扛一部分防守）。 你開牌 range 以外的手牌照理不會走到這個節點，那些格子僅供參考。唯讀（沒有手打的建議表可編輯）。

    面對 limp（iso-raise / 跟 limp）

    現場滿桌 limper，但市面上幾乎沒有這種圖。前面 1–2 家 limp，你要 紅 = iso-raise、綠 = 跟 limp（BB＝過牌）還是灰 = 蓋牌。 iso 的本質：用大牌收「打不中就棄」的便宜錢，並把局面收成有位置的單挑。

    limper 的 range 是「封頂的中段」：超強牌（約前 4%）多半直接加注， 所以模型的 limper range = 最強 X% 去掉最上面 4% —— 面對沒有大對子的 range， ATo 都有近 60% 勝率，這就是 iso 圖比一般開牌圖更寬的原因。 拿 AA limp 設陷阱的人存在，那是 exploit 面，不進模型。唯讀（沒有手打的建議表可編輯）。

    BB 特殊：沒人加注時過牌免費，不存在棄牌 —— 紅色以外全是過牌。 15bb 以淺 iso 建議直接全下。尺度：有位置 4bb / 無位置 5bb，每多一個 limper +1bb。

    翻後 c-bet 速查

    輸入翻牌，看牌面質地、建議的持續下注頻率與尺度，以及你手上這手牌該怎麼打。 濕度 = 同花成分與順子成分各半（0 = 全乾、1 = 全濕）。建議為公認啟發式，非 solver 輸出。

    MDF / 詐唬比速查

    MDF（最低防守頻率）= 底池 ÷（底池＋下注）：棄牌多過這個數，對手隨便詐唬都賺。 跟注賠率 = 下注 ÷（底池＋2×下注），同時也是「對手下注 range 裡 bluff 該占的比例」—— 對手 bluff 比這個多就跟，比這個少就棄。

    訓練測驗

    Push/Fold：隨機籌碼深度與手牌，依 Nash 均衡判斷推或棄。 開牌 RFI：隨機位置、手牌與有效籌碼，判斷開牌或蓋牌（≤20bb 的開牌等於全下）。 面對開牌：隨機防守情境與有效籌碼，判斷 3-bet、跟注或蓋牌。 被 3-bet：隨機情境與有效籌碼（10–300bb），判斷 4-bet、跟注或蓋牌； 淺籌碼時 4-bet 等於全下，該題就沒有跟注選項。 冷 4-bet：前面有人開牌又有人 3-bet，隨機情境、對手 3-bet 寬度與籌碼深度， 判斷冷 4-bet、冷跟還是蓋牌 —— 題目會直接告訴你對手 3-bet 多寬，因為那是決定性的資訊。 面對 4-bet：你 3-bet 後被 4-bet 回來，判斷 5-bet、跟注還是蓋牌（一樣會告訴你對手 4-bet 多寬）。 Squeeze：前面開牌加平跟，判斷 squeeze、跟注還是蓋牌。 面對 squeeze：你開牌、有人跟注後被 squeeze，判斷 4-bet、跟注還是蓋牌（會告訴你對手 squeeze 多寬）。 面對 limp：前面 1–2 家 limp，判斷 iso-raise、跟 limp 還是蓋牌（BB 是過牌）。 翻後 c-bet：隨機翻牌、手牌、位置與底池類型，判斷下注 75%、下注 33% 還是過牌。 河牌接 bluff：對手在河牌下注，依他 range 裡的 bluff 比例與你的底池賠率決定跟或棄。

    📌 測驗以建議 range 為準，圖表的自訂編輯不影響評分。 翻前四種題型在門檻附近是混合策略，只要你選的動作在模型裡有 ≥25% 頻率就算對。
